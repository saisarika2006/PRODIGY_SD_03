# 📞 Contact Management System
## 📌 Overview
The Contact Management System is a simple console-based Python application designed to store and manage contact information efficiently.  
This project was developed as part of an internship task to demonstrate basic Python programming, file handling, and menu-driven applications.

## 🎯 Objectives
- To understand Python basics
- To implement CRUD operations (Create, Read, Update, Delete)
- To use file handling for persistent data storage
- To build a beginner-friendly console application
  
## 🛠️ Technologies Used
- Python
- JSON (for storing contact data)
  
## ✨ Features
- Add new contacts (Name, Phone Number, Email)
- View all saved contacts
- Edit existing contacts
- Delete contacts
- Persistent storage using a JSON file
- Simple and user-friendly interface
  
## 📂 Project Structure
Contact-Management-System/

├── contact_manager.py # Main application file

### 💾 Data Storage
All contacts are stored in a file named contacts.json.
This ensures that data is saved even after the program is closed.
Example:
[
    {
        "name": "Sai",
        "phone": "9876543210",
        "email": "sai@gmail.com"
    }
]
